# 报告编辑界面布局需求分析文档

> 版本：v1.0  
> 日期：2026-08-16  
> 状态：初稿

---

## 1. 概述

本文档描述医学影像报告系统中 **报告编辑界面** 的布局结构及功能区域划分，明确了各模块的定位、组成元素、交互关系，为 UI 设计与前端开发提供需求依据。

---

## 2. 界面整体布局

界面采用 **「三栏 + 顶底」** 结构，从上到下依次为：

```
┌──────────────────────────────────────────────────────────────┐
│  [顶部导航栏]                                                │
├───────────────┬──────────────────────────────┬───────────────┤
│               │                              │               │
│               │                              │               │
│  左侧         │    报告主体内容区             │  右侧侧边栏   │
│  空白/保留    │                              │  (模板区)     │
│  区域         │                              │               │
│               │                              │               │
│               │                              │               │
├───────────────┴──────────────────────────────┴───────────────┤
│  [底部工具栏]                                                │
└──────────────────────────────────────────────────────────────┘
```

### 2.1 布局层级

| 层级 | 区域名称 | 说明 |
|------|----------|------|
| 第一层 | 顶部导航栏 | 全局导航、报告切换、功能入口 |
| 第二层 | 左侧区域 | 预留空间（可扩展为缩略图列表、历史记录等） |
| 第二层 | 报告主体内容区 | 报告编辑核心区域，包含头部、患者信息、所见、意见、签名 |
| 第二层 | 右侧侧边栏 | 报告模板管理面板 |
| 第三层 | 底部工具栏 | 辅助操作、紧急操作、状态变更 |

---

## 3. 顶部导航栏

### 3.1 位置
界面最顶部，通栏横跨整个界面宽度。

### 3.2 功能元素

| 编号 | 元素 | 类型 | 说明 |
|------|------|------|------|
| 3.2.1 | 返回按钮 | 图标按钮 | 返回上一级页面/列表 |
| 3.2.2 | 报告标签页标题 | 文本标签 | 显示当前报告的名称（如患者姓名） |
| 3.2.3 | 上一个/下一个导航 | 按钮组 | 切换同一检查序列中的前后报告 |
| 3.2.4 | 状态指示器 | 文本 + 图标 | 显示当前报告的锁定状态（如「未锁定」「已锁定」） |
| 3.2.5 | 影像 | 图标按钮 | 切换/打开影像查看器 |
| 3.2.6 | 报告 | 图标按钮 | 返回/聚焦报告编辑区 |
| 3.2.7 | 申请单 | 图标按钮 | 查看/切换申请单详情 |
| 3.2.8 | 对比 | 图标按钮 | 进入对比模式（多报告/多影像对照） |
| 3.2.9 | 收藏 | 图标按钮 | 收藏当前报告到个人收藏夹 |
| 3.2.10 | 同屏互动 | 图标按钮 | 开启远程会诊/同屏协作 |

### 3.3 布局说明
- 返回按钮居左
- 报告标题 + 导航按钮组居中靠左
- 功能图标按钮组居右排列

---

## 4. 报告头部

### 4.1 位置
导航栏下方，患者基本信息区上方。

### 4.2 功能元素

| 编号 | 元素 | 类型 | 说明 |
|------|------|------|------|
| 4.2.1 | 患者姓名 | 大号文本 | 主标题，醒目显示 |
| 4.2.2 | 就诊类型标签 | 标签 | 如「住院」「门诊」「急诊」，带颜色区分 |
| 4.2.3 | 报告状态 | 图标 + 文本 | 如「已审核」「待审核」「已提交」 |
| 4.2.4 | 医院名称 | 文本 | 当前检查所属医疗机构 |
| 4.2.5 | 报告模板 | 按钮 | 快速选择/套用报告模板 |
| 4.2.6 | 关联检查 | 按钮 | 查看/关联同患者的其他检查 |
| 4.2.7 | 修改记录 | 按钮 | 查看报告的修改历史 |
| 4.2.8 | 报告对比 | 按钮 | 与历史报告进行内容对比 |

### 4.3 布局说明
- 患者姓名 + 就诊标签 + 报告状态 居左
- 医院名称 在姓名下方居左
- 四个操作按钮居右对齐

## 5. 患者基本信息区

### 5.1 位置
报告头部下方，采用网格布局。

### 5.2 字段组

#### 5.2.1 第一行——患者身份信息
| 字段 | 类型 | 说明 |
|------|------|------|
| 患者号 | 文本输入框（只读） | 患者唯一标识 |
| 姓名 | 文本输入框（只读） | 患者姓名 |
| 性别 | 下拉选择器（只读） | 男/女/其他 |
| 年龄 | 文本输入框（只读） | 年龄+单位（岁/月/天） |

#### 5.2.2 第二行——检查信息
| 字段 | 类型 | 说明 |
|------|------|------|
| 检查部位 | 文本/多选标签 | 如「胸部、腹部」 |
| 部位数量 | 数字/下拉 | 选择的部位总数 |
| 检查类型 | 文本/下拉 | 如 DX（X线）、CT、MR、US 等 |
| 检查时间 | 日期时间选择器（只读） | 检查执行时间 |

#### 5.2.3 第三行——检查方法
| 字段 | 类型 | 说明 |
|------|------|------|
| 检查方法标签 | 标签 | 固定文本 |
| 申请单内容 | 多行文本区域（只读） | 临床诊断/申请理由 |
| 存为模板 | 按钮 | 将当前检查方法存为个人模板 |

#### 5.2.4 补充行
| 字段 | 类型 | 说明 |
|------|------|------|
| 检查方法描述 | 文本输入框 | 自由输入检查方法描述，如「胸部、腹部卧位平片--」 |

### 5.3 布局说明
- 采用三列或四列网格布局
- 每个字段右侧显示锁定图标（只读状态）
- 第三行左右跨度较大，右侧放置「存为模板」按钮

## 6. 影像所见（Findings）

### 6.1 位置
患者基本信息区下方。

### 6.2 功能元素

| 编号 | 元素 | 类型 | 说明 |
|------|------|------|------|
| 6.2.1 | 标题 | 文本标题 | 「影像所见」 |
| 6.2.2 | 内容编辑区 | 多行富文本编辑器 | 支持格式化文本、医学符号、快捷输入 |

- 编辑区占据可用宽度，高度自适应

## 11. 交互需求

### 11.1 导航交互
- 报告标签页支持 Tab 切换，多报告时可滑动
- 上一个/下一个按钮支持循环或边界禁用

### 11.2 编辑交互
- 所见和意见编辑区支持富文本编辑（加粗、斜体、列表、表格等）
- 支持快捷键：Ctrl+S 保存、Ctrl+Enter 提交
- 支持从右侧模板区拖拽/点击插入模板内容

### 11.3 状态管理
- 报告状态包括：未锁定、编辑中、已锁定、已提交、已审核、已发布
- 状态变更需有确认弹窗
- 只读字段在锁定状态下不可编辑

### 11.4 响应式布局
- 右侧侧边栏支持折叠/展开（响应式切换）
- 最小支持 1280px 宽度
- 在窄屏下，顶部功能图标可合并到「更多」菜单中

## 12. 视觉规范（建议）

| 元素 | 规范 |
|------|------|
| 就诊类型标签 | 住院=橙色，门诊=蓝色，急诊=红色 |
| 报告状态 | 已审核=绿色，待审核=黄色，退回=红色 |
| 患者姓名 | 字号 18-20px，加粗 |
| 标题 | 字号 14-16px，加粗，带下划线或左侧色条 |
| 编辑区 | 白色背景，边框 1px solid #ddd，圆角 4px |
| 按钮 | 主按钮=蓝色(#1890ff)，文字按钮=灰色 |
| 锁定图标 | 灰色小锁图标，尺寸 12x12px |
