## 3. 功能收尾

### 3.1 机构审核闭环开关

- 管理员 API：`GET /api/v1/institution/settings`、`PATCH /api/v1/institution/settings`。
- 服务端根据当前管理员所属机构读写 `institutions.review_required`，不存在跨机构写入入口。
- 非管理员返回 `403`，且拒绝请求不会改变数据库设置。
- 更新成功后写入 `institution_settings_changed` 审计事件。
- 管理控制台新增“机构设置”页面和“报告审核闭环”开关；保存后无需重启即可影响报告工作流。
- 数据库测试覆盖默认关闭、管理员开启、跨请求持久化、医生无权读写和拒绝写入不改变状态。

### 3.2 文档与打包链

- README 已勾选高级工作列表，并增加报告审核、申请单、工作量统计交付项。
- Windows 安装器版本从 `tauri.conf.json` 读取，目标文件名为 `AETHERIS-Setup-0.3.0-x64.exe`。
- GitHub Actions artifact 名称包含版本号。
- `Cargo.lock` 内部工作区版本已同步至 `0.3.0`。
- macOS 内置服务日志不再输出明文随机密码字段。
- 论文 HTML 未加入源码提交，已归档至 `temp/release-0.3.0/aetheris-pacs-software-engineering-paper.html`。
