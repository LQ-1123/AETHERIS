# P0 Viewer 推进计划

> 创建日期：2026-08-15
> 来源：`doc/competitor-comparison.md` 中的 P0 项。
> 目标：把 Viewer 从“单视口 + 固定 MPR + 基础 VR”推进到“放射科级基础阅片工作台”。

## P0 范围

| 编号 | 任务 | 目标 |
|---|---|---|
| P0-0 | ViewportSession 多视口抽象 | 前端支持多个独立 2D 视口会话 |
| P0-1 | 多窗口分屏看图 | 1x1 / 1x2 / 2x1 / 2x2 / 2x3 / 3x3，多序列同屏对比 |
| P0-2 | 2D 多序列同步 + 扫描定位线 | 同步翻层/窗宽窗位/缩放平移，显示 cross-reference lines |
| P0-3 | VR 窗宽窗位专业交互 | VR 视口内拖拽调窗，精确输入，裁剪/去床板 |
| P0-4 | 多角度 MPR / CPR | 任意斜位切面 + 曲面重建 |

## 执行顺序

- 第 1 周：P0-0 + P0-3
- 第 2 周：P0-1
- 第 3 周：P0-2
- 第 4～5 周：P0-4a 任意角度/斜位 MPR
- 第 5～6 周：P0-4b CPR

## 实施记录

- 2026-08-15：P0-3 VR 视口拖拽调窗已实现（`setInteractionsEnabled`、`vr-window-tool`、拖拽映射：水平调窗位/垂直调窗宽）。
- 2026-08-15：新增 `series-sync.ts` 纯几何工具（切片位置映射 + 定位线求交）及单测，用于 P0-2。
- 进行中：P0-0/P0-1 多视口布局。

## 验收标准

- [ ] `npx tsc --noEmit` 通过
- [ ] `npm test -- --run` 通过
- [ ] 多窗格可打开不同序列并独立翻层/调窗/测量
- [ ] 同平面序列可按患者空间位置同步
- [ ] VR 可拖拽调窗并与滑块双向同步
- [ ] MPR 可旋转定位线生成斜位切面（P0-4a）
