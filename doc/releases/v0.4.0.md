# AETHERIS v0.4.0 发布说明

发布日期：2026-08-20

本版本补齐 DICOM Query/Retrieve 的 C-MOVE 与 C-GET，并提供管理员主动从外部 PACS 拉取检查的入口。

## 重点更新

- C-MOVE SCP：按 Study Root 检索，使用 C-STORE 推送原始归档实例，响应包含 remaining/completed/failed/warning 子操作计数。
- C-GET SCP：在同一 association 内返回 C-STORE 子操作。
- C-FIND/C-MOVE SCU：管理控制台可配置已批准设备为检索源、查询远端检查并拉取入库。
- 持久化拉取任务：C-MOVE 由后台 worker 执行，管理控制台展示 Pending 子操作进度、成功/失败/警告计数并支持合作式 C-CANCEL。
- 安全边界：Move Destination 只允许本机 AE 或机构内已批准且配置端口的设备；管理 API 仅管理员可用。
- 数据治理：外部 PACS 回传继续进入既有 C-STORE 入库链路，保留幂等、来源设备归属和机构/设备授权边界。

## 升级

`pacsd` 启动时自动应用迁移 `0032_dicom_retrieval.sql` 与 `0033_retrieval_jobs.sql`。升级前仍应备份 PostgreSQL 与 DICOM 存储目录。

## 验收

- Rust workspace check、DIMSE/Web 定向测试、Clippy 和格式检查。
- Viewer TypeScript/Vite 构建。
- Playwright 管理界面验收截图输出到 `temp/playwright/v0.4.0/`。

仓库内互操作测试使用本机 PostgreSQL 与 DCMTK 验证协议实现；生产部署仍需结合实际对端 PACS、网络 ACL、AE/端口和 TLS 证书完成现场联调。
